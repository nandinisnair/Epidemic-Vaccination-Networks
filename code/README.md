# Historical Exploratory Notebooks

This directory contains the original exploratory Jupyter notebooks developed during the preliminary phases of the research:
- `epidemicspreading.ipynb`: Initial interactive experiments with graph loading, degree distributions, and prototype SI/SIR loops.
- `Ex2.ipynb`, `Ex3.ipynb`: Supplementary exploratory scratchpads.

For the production-grade, modular, and fully tested pipeline, refer to the root `src/` and `experiments/` directories.
