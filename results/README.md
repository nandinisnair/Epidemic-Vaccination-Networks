# Experimental Results and Artifacts

This directory houses all generated outputs from the simulation pipeline:

- `plots/`: Publication-quality figures (300 DPI PNG) illustrating network topology, degree distribution, centrality comparisons, epidemic progressions, and multi-strategy vaccination evaluations.
- `tables/`: Structured CSV summary tables including network statistics, top influential nodes, and aggregated vaccination benchmarks.
- `centrality_rankings/`: Complete node-level rankings for all 217 individuals across Degree, Strength, Betweenness, and Weighted Betweenness.
- `simulation_outputs/`: Raw Monte Carlo run logs (8,500 total simulations) recording individual trajectory metrics for statistical auditing and verification.
